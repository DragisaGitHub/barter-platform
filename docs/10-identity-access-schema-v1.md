# Identity & Access Schema V1

## Goal

Define the first database schema for identity, authentication, authorization and account security.

This document is the source for the first Flyway migration:

    V001__initial_identity_access_schema.sql

---

## Tables Included

V1 includes:

- users
- roles
- permissions
- user_roles
- role_permissions
- oauth_accounts
- refresh_tokens
- user_mfa_settings
- user_mfa_recovery_codes

---

# Common Rules

All major tables use:

- id BIGINT primary key
- uuid UUID unique not null
- created_at timestamp with time zone not null
- updated_at timestamp with time zone
- deleted_at timestamp with time zone where soft delete is needed

UUID values are generated by the backend application.

---

# users

Stores platform user accounts.

## Columns

- id BIGSERIAL primary key
- uuid UUID not null
- username VARCHAR(80) not null
- email VARCHAR(255) not null
- password_hash VARCHAR(255)
- status VARCHAR(40) not null
- email_verified BOOLEAN not null default false
- mfa_enabled BOOLEAN not null default false
- last_login_at TIMESTAMP WITH TIME ZONE
- created_at TIMESTAMP WITH TIME ZONE not null
- updated_at TIMESTAMP WITH TIME ZONE
- deleted_at TIMESTAMP WITH TIME ZONE

## Constraints

- uq_users_uuid unique(uuid)
- uq_users_username unique(username)
- uq_users_email unique(email)

## Indexes

- idx_users_status(status)
- idx_users_created_at(created_at)

## Status Values

- PENDING_VERIFICATION
- ACTIVE
- SUSPENDED
- BANNED
- DELETED

# user_roles

Connects users and roles.

## Columns

- user_id BIGINT not null
- role_id BIGINT not null
- assigned_at TIMESTAMP WITH TIME ZONE not null
- assigned_by BIGINT

## Constraints

- pk_user_roles primary key(user_id, role_id)
- fk_user_roles_user foreign key(user_id) references users(id)
- fk_user_roles_role foreign key(role_id) references roles(id)
- fk_user_roles_assigned_by foreign key(assigned_by) references users(id)

## Indexes

- idx_user_roles_user_id(user_id)
- idx_user_roles_role_id(role_id)

---

# role_permissions

Connects roles and permissions.

## Columns

- role_id BIGINT not null
- permission_id BIGINT not null
- assigned_at TIMESTAMP WITH TIME ZONE not null

## Constraints

# oauth_accounts

Stores linked external OAuth provider accounts.

## Columns

- id BIGSERIAL primary key
- uuid UUID not null
- user_id BIGINT not null
- provider VARCHAR(40) not null
- provider_user_id VARCHAR(255) not null
- provider_email VARCHAR(255)
- linked_at TIMESTAMP WITH TIME ZONE not null
- created_at TIMESTAMP WITH TIME ZONE not null
- updated_at TIMESTAMP WITH TIME ZONE

## Constraints

- uq_oauth_accounts_uuid unique(uuid)
- uq_oauth_accounts_provider_user unique(provider, provider_user_id)
- fk_oauth_accounts_user foreign key(user_id) references users(id)

## Indexes

- idx_oauth_accounts_user_id(user_id)
- idx_oauth_accounts_provider(provider)

## Provider Values

- GOOGLE
- APPLE

# refresh_tokens

Stores hashed refresh tokens.

## Columns

- id BIGSERIAL primary key
- uuid UUID not null
- user_id BIGINT not null
- token_hash VARCHAR(255) not null
- expires_at TIMESTAMP WITH TIME ZONE not null
- revoked_at TIMESTAMP WITH TIME ZONE
- created_at TIMESTAMP WITH TIME ZONE not null
- device_info VARCHAR(500)
- ip_address VARCHAR(80)

## Constraints

- uq_refresh_tokens_uuid unique(uuid)
- uq_refresh_tokens_token_hash unique(token_hash)
- fk_refresh_tokens_user foreign key(user_id) references users(id)

## Indexes

- idx_refresh_tokens_user_id(user_id)
- idx_refresh_tokens_expires_at(expires_at)
- idx_refresh_tokens_revoked_at(revoked_at)

---

# user_mfa_settings

Stores MFA configuration per user.

## Columns

- id BIGSERIAL primary key
- uuid UUID not null
- user_id BIGINT not null
- secret_encrypted TEXT not null
- enabled BOOLEAN not null default false
- configured_at TIMESTAMP WITH TIME ZONE
- created_at TIMESTAMP WITH TIME ZONE not null
- updated_at TIMESTAMP WITH TIME ZONE

## Constraints

- uq_user_mfa_settings_uuid unique(uuid)
- uq_user_mfa_settings_user_id unique(user_id)
- fk_user_mfa_settings_user foreign key(user_id) references users(id)

---

# user_mfa_recovery_codes

Stores hashed MFA recovery codes.

## Columns

- id BIGSERIAL primary key
- user_mfa_settings_id BIGINT not null
- code_hash VARCHAR(255) not null
- used_at TIMESTAMP WITH TIME ZONE
- created_at TIMESTAMP WITH TIME ZONE not null

## Constraints

- uq_user_mfa_recovery_codes_code_hash unique(code_hash)
- fk_user_mfa_recovery_codes_settings foreign key(user_mfa_settings_id) references user_mfa_settings(id)

## Indexes

- idx_user_mfa_recovery_codes_settings_id(user_mfa_settings_id)

---

# Notes

- Password hash can be null for OAuth-only accounts.
- Refresh tokens must be stored only as hashes.
- MFA secrets must be encrypted before storage.
- Physical delete should be avoided for users.
- Roles and permissions are seeded through migrations or application bootstrap logic.
