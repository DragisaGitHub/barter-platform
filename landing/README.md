
  # Create a responsive landing page

  This is a code bundle for Create responsive landing page. The original project is available at https://www.figma.com/design/SLfctAlQgABZckeLmj5b5h/Create-responsive-landing-page.

  ## Running the code

  Run `yarn install --frozen-lockfile` to install the dependencies.

  Run `yarn dev` to start the development server.

  Run `yarn build` to create a production build.

  Optionally set `VITE_DEMO_URL` if you want to override the default demo link target.
